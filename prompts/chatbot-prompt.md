한의원 데스크 직원용 AI 예약 챗봇 에이전트를 만들어줘. Google Sheets 연동과 Function Calling을 추가한 다음 의사, 치료실, 치료를 선택를 유저의 요청에 따라 비어있는 slot에 예약을 해줄지 물어와야 해.

## 핵심 원칙
1. 데이터에 근거한 답변만 한다.
2. temperature는 0.2로 고정한다.

## 화면 구성
- 화면 상단: "한의원 예약 도우미" 타이틀과 짧은 설명 문구
- 화면 중앙: 채팅 메시지가 쌓이는 대화창 (사용자 메시지는 오른쪽 말풍선, AI 응답은 왼쪽 말풍선)
- 화면 하단: 텍스트 입력창 + 전송 버튼. Enter 키로도 전송 가능하게
- 로딩 중에는 AI 말풍선 자리에 "생각 중..." 같은 타이핑 인디케이터 표시

## 동작
1. 사용자가 자연어로 질문을 입력하면 (예: "8월 17일 오후에 부항 예약 가능한 시간 있어?")
2. Gemini API를 호출해서 AI가 그 의도를 판단하고 자연어로 답변
3. 대화 기록은 메시지 배열(role: user/model) 형태로 상태 관리해서, 나중에 함수 호출(function calling) 결과를 이 배열에 끼워 넣기 쉬운 구조로 만들어

## Gemini API 설정
- generationConfig의 temperature를 0.2로 고정, 할루시네이션을 줄이기 위한 의도이니 다른 값으로 바꾸지 마
- 모델은 최신 Gemini Flash 계열 사용

## 디자인
- 폰트는 Pretendard 사용, CDN 링크: https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css
- 전체적으로 깔끔하고 신뢰감 있는 톤 (과한 색감이나 이모지 금지)
- 메인 컬러는 차분한 그린 또는 딥블루 계열
- 모바일 화면(태블릿 크기)에서도 잘 보이도록 반응형으로 설계
- 병원 데스크에 놓인 태블릿에서 쓸 걸 가정하고, 버튼과 입력창은 터치하기 편한 크기로
- 치료 항목(침, 부항, 추나, 물리치료, 기타)와 시간을 5분 단위로 쪼개고 드롭다운으로 유저가 메세지 창 위에 선택
- 그리고 새로운 버튼을 만들어서 클릭하면 시간 단위로 하루의 진료실 상태를 볼 수 있게도 해줘.

## Google Sheets 연동
- Google Workspace 연동 기능을 사용해서 사용자가 자기 Google 계정으로 로그인하고, 자기 소유의 Google Sheet를 선택할 수 있게 해줘
- 시트 구조: 날짜, 시간, 원장, 시술종류, 소요시간(분), 예약상태(비어있음/예약됨) 컬럼
- AI Studio의 내장 Workspace 연동 방식으로 시트 선택 UI를 만들어
- 별도의 수동 클라이언트 ID(VITE_GOOGLE_CLIENT_ID)가 필요한 커스텀 로그인/피커 방식은 쓰지 마

## Function 정의
- get_available_slots라는 함수를 만들어줘.
- 입력 파라미터: date(YYYY-MM-DD 형식), treatment_type(시술종류, 선택사항), doctor(원장명, 선택사항)
- 동작: 연결된 시트에서 해당 조건에 맞고 예약상태가 "비어있음"인 행을 모두 찾아서 반환
- 조건에 맞는 게 하나도 없으면 빈 배열을 반환하고, 그 이유를 함께 반환해줘 (예: "해당 날짜 데이터 없음" vs "데이터는 있지만 모두 예약됨" — 이 둘을 구분해야 함)

## 에이전트 동작 흐름 
### 반드시 이 순서를 지켜야 함
1. 사용자 질문을 받으면, 먼저 답변을 생성하지 말고 get_available_slots 함수부터 호출해서 실제 데이터를 조회한다
2. 함수 결과를 받으면, 답변을 만들기 전에 아래를 스스로 점검한다:
2-1. 사용자가 물어본 날짜/시술종류와 조회한 조건이 정확히 일치하는가?
2-2. 함수가 빈 배열을 반환했다면, 그게 "재고 없음"인지 "데이터 자체가 없음"인지 구분했는가?
2-3. 여러 원장의 슬롯이 섞여 있다면, 사용자가 원장을 특정하지 않은 경우 이를 명확히 구분해서 안내할 것인가?
3. 위 점검을 통과한 경우에만 최종 답변을 생성한다. 점검에서 문제가 발견되면(데이터 불명확, 조건 불일치 등) 추측하지 말고 사용자에게 되물어본다
4. 함수 호출 없이 자체 지식만으로 예약 가능 여부를 답변하는 것은 절대 금지. 시트 데이터에 없는 내용은 "확인이 필요하다"고 명시적으로 답변할 것

## 시스템 프롬프트에 반드시 포함할 문구
"너는 한의원 예약 슬롯을 조회하는 AI 에이전트다. 절대 추측으로 답변하지 말고, 항상 get_available_slots 함수를 호출해서 얻은 실제 데이터에만 근거해서 답변해라. 함수 호출 결과가 애매하거나 부족하면 사용자에게 명확히 되물어라."

## 화면에 반영
- 함수를 호출 중일 때는 "예약 현황 확인 중..." 같은 상태 표시를 채팅창에 보여줘
- 답변에는 어떤 조건으로 조회했는지(날짜, 시술종류, 원장) 간단히 함께 보여줘서, 데스크 직원이 AI가 뭘 근거로 답했는지 바로 확인할 수 있게 해줘
- temperature는 1단계와 동일하게 0.2 유지

## 에러 처리
- Sheets 연결이 끊기거나 함수 호출이 실패하면, 채팅창에 "예약 시스템 연결에 문제가 있습니다. 잠시 후 다시 시도해주세요"라고 명확히 안내하고, 절대 임의의 답변을 만들어내지 마
